Meta Header

This page is a live demonstration. Its source begins with a JSON block terminated by a
__meta__ line:

{
    "icon" : "fa-star"
}
__meta__

# Meta Header
...

… which is why it carries a star in the menu instead of the usual page icon.

Everything above the __meta__ line is lifted out and read as settings; everything below
it is ordinary markdown. If the JSON doesn't parse, Documon leaves the page alone rather
than mangling it, so a typo costs you the icon and nothing else.

The properties

`icon`

A CSS class for the menu entry. Documon ships Font Awesome,
so any of their class names work. Space-delimit to apply more than one.

`url`

Turns the entry into a link to somewhere outside the generated site. When url is set
no page is written for the file at all -- the menu entry simply points elsewhere, and
whatever you wrote below the __meta__ line is never published. That is the intent, but
it does mean an accidental url makes a page silently vanish.

Only the first boundary counts

The split happens at the first __meta__, so you can mention the word further down the
page -- as this sentence does -- without confusing the parser.
